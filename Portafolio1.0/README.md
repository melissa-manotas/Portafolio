# Portafolio de Melissa Manotas

Este es el portafolio personal de Melissa Manotas, una desarrolladora web principiante. Este proyecto muestra las habilidades y proyectos de Melissa, así como su información de contacto.

## Estructura del Proyecto

El proyecto tiene la siguiente estructura de archivos:

```
portafolio-melissa
├── index.html               # Documento HTML principal del portafolio
├── assets
│   ├── css
│   │   └── styles.css       # Estilos CSS para el portafolio
│   ├── javascript
│   │   └── script.js        # Código JavaScript para interactividad
│   └── img
│       └── (imagenes no incluidas)  # Imágenes utilizadas en el portafolio
├── .gitignore               # Archivos y directorios que Git debe ignorar
└── README.md                # Documentación del proyecto
```

## Instalación

1. Clona el repositorio en tu máquina local:
   ```
   git clone https://github.com/tu_usuario/portafolio-melissa.git
   ```

2. Navega al directorio del proyecto:
   ```
   cd portafolio-melissa
   ```

3. Abre el archivo `index.html` en tu navegador para ver el portafolio.

## Uso

Este portafolio está diseñado para mostrar las habilidades y proyectos de Melissa. Puedes navegar a través de las diferentes secciones utilizando el menú de navegación.
